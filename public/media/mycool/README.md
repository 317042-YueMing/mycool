# Mycool screenshots

- `v2-desktop.png`: Playwright capture of the running Mycool V2 page before the Refero redesign, viewport 1440 × 1000, device scale factor 2 (2880 × 2000 pixels).
- `v2-mobile.png`: same page, viewport 390 × 844, device scale factor 2 (780 × 1688 pixels).
- Source: the project's existing development server at `http://127.0.0.1:3000/`.
- Capture excluded only the Next.js development indicator through screenshot-time CSS. Page content, typography and layout were not modified for these captures.
- These are historical development captures, explicitly labeled as pre-redesign V2 in the project caption. They are not mockups of a future page and are not screenshots of robotics or LSTM software.
- Page rendering uses the original PNGs via `next/image`. The gallery scales and partially crops the desktop capture at narrow widths; original desktop and mobile files remain accessible through links.
